# 젬 거래소 · 웹사이트 설치 안내서

포켓몬카드(영문판·일판 SAR 이상) 실제 시세로 연습하는 모의투자 웹사이트예요.
앱스토어 앱이 아니라 웹사이트이고, 사용자는 "홈 화면에 추가"로 앱처럼 쓸 수 있어요.

- 서버: **Supabase** (무료 요금제로 시작 가능) — 계정, 잔고, 주문, 시세 엔진
- 사이트 호스팅: **GitHub Pages** (무료) — 화면 파일
- 모든 거래는 서버 함수에서만 처리돼서, 브라우저에서 잔고를 조작할 수 없어요.

## 현재 설정 상태 (2026-11-10)

- 사이트: https://challengeletgo.github.io/gem-exchange/
- Supabase 프로젝트: `gem-exchange` (서울 리전, 조직 slab-blind) — 표·거래 함수·시세 엔진 설치 완료, 익명 로그인 켜짐
- 자동 작업 (Supabase pg_cron)
  - `gem-market-tick` 10초마다 시세 엔진
  - `gem-fx-request` / `gem-fx-apply` 매일 07:30 / 07:33(한국 시간) 원/달러 환율을 받아 전 종목 기준가 재환산
- 카드별 달러 시세: Claude 예약 작업이 매일 07:48에 조사해 `apply_usd_prices`로 반영 (회원님 컴퓨터가 켜져 있을 때)
- 남은 일: 아래 **3단계 운영자 등록**만 직접 해 주시면 돼요.

## 1단계 · Supabase 프로젝트 만들기 (약 10분)

1. https://supabase.com 에 가입하고 **New project**를 눌러요.
   - Region은 **Northeast Asia (Seoul)** 을 고르세요.
   - 데이터베이스 비밀번호는 따로 적어 두세요.
2. **Authentication → Sign In / Providers** 에서 **Anonymous sign-ins** 를 켜요.
   - 사용자가 이메일 없이 닉네임만으로 시작할 수 있게 해 줘요.
3. **Database → Extensions** 에서 **pg_cron** 을 검색해 켜요. (10초마다 시세를 움직이는 엔진이에요)
4. **SQL Editor → New query** 에 `supabase.sql` 내용을 전부 붙여넣고 **Run** 을 눌러요.
   - 끝에 `gem-market-tick` 예약이 만들어지면 성공이에요.
   - 같은 SQL을 다시 실행해도 기존 데이터는 지워지지 않아요. 다만 시세 엔진 예약이 중복될 수 있으니, 다시 실행할 땐 맨 아래 `cron.schedule` 줄은 빼고 실행하세요.
5. **Project Settings → API** 에서 두 값을 복사해 `config.js` 에 넣어요.
   - `Project URL` → `SUPABASE_URL`
   - `anon public` 키 → `SUPABASE_ANON_KEY`
   - ⚠️ `service_role` 키는 절대 넣지 마세요.

## 2단계 · GitHub Pages로 사이트 열기 (약 5분)

1. GitHub에서 새 저장소를 만들어요. (예: `gem-exchange`, Public)
2. **Add file → Upload files** 로 이 폴더의 파일을 전부 올려요. (`supabase.sql`, `README.md`는 올려도 되고 안 올려도 돼요)
3. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 저장해요.
4. 1~2분 뒤 `https://내아이디.github.io/gem-exchange/` 로 접속돼요.

## 3단계 · 운영자 등록

1. 사이트에 접속해서 닉네임과 나이로 가입해요.
2. 같은 기기에서 `.../admin.html` 을 열면 "운영자만 할 수 있어요"와 함께 **계정 ID** 가 보여요.
3. Supabase **SQL Editor** 에서 아래를 실행해요.
   ```sql
   insert into public.admins values ('여기에-계정-ID');
   ```
4. 이제 거래 화면 상단에 **운영자 페이지** 버튼이 생겨요.

> 계정은 기기(브라우저)마다 따로 만들어져요. 다른 기기에서도 운영하려면 그 기기의 계정 ID도 같은 방법으로 등록하세요.

## 4단계 · 기준가 자동 갱신 연결

1. 운영자 페이지 → **예약 작업용 시세 토큰 → 새 토큰 만들기** 를 눌러요. 토큰은 그때 한 번만 보여요.
2. Claude에게 **사이트 주소, Supabase Project URL, anon key, 토큰** 을 알려 주세요.
   매일 개장 전(07:48)에 시세와 환율을 조사해서 기준가를 갱신하는 예약 작업이 이 사이트로 연결돼요.
3. 토큰이 새어 나갔다면 운영자 페이지에서 새로 만들면 이전 토큰은 바로 무효가 돼요.

## 홈 화면 바로가기

사이트에 처음 들어오면 안내 배너가 떠요.
- **안드로이드(크롬)**: 배너의 "홈 화면에 추가" 버튼, 또는 메뉴(⋮) → 홈 화면에 추가
- **아이폰(사파리)**: 아래쪽 공유 버튼 → 홈 화면에 추가

유튜브 설명란이나 채널 프로필 링크에 사이트 주소를 넣고, "홈 화면에 추가하면 앱처럼 쓸 수 있어요"라고 안내하면 돼요.

## 알아 두면 좋은 점

- **무료 요금제**: Supabase 무료 프로젝트는 일주일 동안 접속이 없으면 일시정지될 수 있어요. 사람이 늘면 유료(Pro) 전환을 고려하세요.
- **봇 가입 방지**: 사람이 많아지면 Authentication → Attack Protection 에서 CAPTCHA를 켜는 걸 추천해요.
- **계정 이동**: 익명 계정이라 브라우저 데이터를 지우거나 기기를 바꾸면 계정이 새로 만들어져요. 나중에 이메일 로그인을 붙이면 이어서 쓸 수 있어요.
- **저작권**: 카드 이름은 텍스트로만 쓰고, 공식 카드 이미지는 넣지 않았어요. 하단에 "포켓몬 컴퍼니와 관련 없음"을 표시해요.
- **가상 화폐**: 젬은 충전·환전·현금화가 전혀 없는 연습용 단위예요. 경품을 젬 순위와 연결하는 이벤트를 할 때는 경품 관련 법규를 한 번 확인하세요.
